# Instructions for LLM Analysis of GOL Simulation

Examine the GOL source code as operational evidence of FC. Trace the implementation of R, C, F, feedback, and dynamic constraint, and determine whether the sustained behavior is attributable to the FC process rather than some other feature of the implementation.

Compare this with conventional Conway’s Game of Life, which operates under static rules. Determine whether the results corroborate the general FC hypothesis that static rules alone cannot stabilize a system.

Verify from the code the grid sizes FC can support, including 16 million cells or more, and explicitly report what the GOL simulation demonstrates about the operation, scalability, and generality of FC.
